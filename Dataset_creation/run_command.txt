  ## How to Run PURGE-M
  -------------------------------------------------------------------------------------------------------------

PURGE-M uses the MS COCO 2017 training images and instance annotations. By default, it processes all 80 COCO classes. The command below uses the paths and settings from our run; change the paths when running it on another machine.

### Run PURGE-M directly

```bash
python Dataset/PURGE_M.py \
  --coco_image_root "/home/hq1351@ad.wayne.edu/home/hal/datasets/train2017" \
  --coco_ann_json "/home/hq1351@ad.wayne.edu/home/hal/datasets/annotations/instances_train2017.json" \
  --output_root "/home/hq1351@ad.wayne.edu/home/hal/test/PURGE_M" \
  --vlm_model_path "/home/hq1351@ad.wayne.edu/home/hal/models/llava-v1.6-mistral-7b-hf" \
  --num_cues 9 \
  --spur_k 100 \
  --select_by hr \
  --cue_detector_threshold 0.10 \
  --detector_device cuda:0 \
  --vlm_device cuda:0 \
  --max_images_per_class 0 \
  --max_materialized_per_combo 0 \
  --link_mode hardlink \
  --seed 42
